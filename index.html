About Me

Background, philosophy, and approach to software development.

Based in Indonesia 🇮🇩

I am Vrica Gede Penggalih, a software engineer with experience across full-stack web development and low-level software engineering. Beyond traditional web apps, I enjoy engineering custom CLI tools and even built my own interpreted programming language from scratch.

I am a flexible developer comfortable working with various tech stacks—from high-level web frameworks like React and Laravel to raw socket network programming and Go interpreters.

I run Arch Linux as my daily driver. I appreciate its speed, transparency, and alignment with my core engineering belief: simplicity over artificial complexity. When writing software, I strive to embody the UNIX philosophy—building focused, reliable tools that do one thing exceptionally well.
